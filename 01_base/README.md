# SIGEP-Colegio

Sistema de Gestión de Procesos Escolares para la I.E. Emblemática Gran Unidad Escolar Inca Garcilaso de la Vega (Cusco).

Proyecto del curso **Estructura de Datos**, Universidad Continental. Docente: Yesenia Concha Ramos.

## Estructuras de datos implementadas
| Estructura | Uso en el sistema |
|---|---|
| Lista simplemente enlazada | Registro de estudiantes |
| Pila | Historial de acciones (con fecha y hora) |
| Cola de prioridad | Atención de trámites en secretaría |
| Arreglo estático | Tipos de trámite |

## Cómo ejecutar
1. Abrir `SIGEP_Colegio.cpp` en Dev C++.
2. Compilar y ejecutar con F11.
3. Los datos se guardan en `estudiantes.txt`, `historial.txt` y `tramites.txt`.
